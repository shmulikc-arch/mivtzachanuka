# מבצע חנוכה עם אבא

מערכת הרשמה למבצעי חנוכה בבתי הרפואה – ארגון הפנסאים × לב חב"ד.

- `index.html` – דף הנחיתה וההרשמה
- `admin.html` – דשבורד ניהול
- `schema.sql` – מבנה בסיס הנתונים ל־Supabase

**כרגע במצב הדגמה:** ההרשמות נשמרות רק בדפדפן של מי שנרשם. לחיבור לשרת יש למלא `SUPABASE_URL` ו־`SUPABASE_ANON_KEY` בתוך `CONFIG` בשני הקבצים, ולהריץ את `schema.sql` בפרויקט Supabase.
