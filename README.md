# מבצע חנוכה עם אבא

דף הרשמה למבצעי חנוכה בבתי הרפואה (ארגון הפנסאים × לב חב"ד).
פיילוט ראשון: קפלן (רחובות) ווולפסון (חולון), כ"ו–ל' כסלו, עד 10 אבות למשמרת.

- `index.html`: דף הנחיתה וההרשמה
- `apps-script/Code.gs`: הקוד שמקבל את ההרשמות לגוגל שיטס ושומר על המכסה

## חיבור לגוגל שיטס
1. יוצרים גוגל שיט חדש → הרחבות → Apps Script → מדביקים את `apps-script/Code.gs`.
2. פריסה → פריסה חדשה → אפליקציית אינטרנט. הפעלה בתור: אני. גישה: כולם.
3. מעתיקים את הכתובת שמסתיימת ב־`/exec` לתוך `SCRIPT_URL` ב־`index.html`.

ביטול הרשמה: כותבים "בוטל" בעמודת "סטטוס" בגיליון "הרשמות", והמקום מתפנה.

כל עוד `SCRIPT_URL` ריק, הדף במצב הדגמה וההרשמות נשמרות רק בדפדפן.
